 **Medicare — Healthcare Management System** 

> **Developed a MERN healthcare management system to manage patients, doctors, departments and appointments.**
> **Built RESTful APIs with Node.js and Express.js and MongoDB data models for efficient data management.**
> **Implemented JWT authentication and Role-Based Access Control (RBAC) for Admin, Doctor, Staff and Patient.**
> **Developed responsive React.js interfaces with appointment scheduling, user management and secure authorization.**
> **Designed a scalable, deployment-ready architecture following modular full-stack development practices.**
